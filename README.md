# Análise de Vendas com SQL

Projeto desenvolvido para praticar SQL e conceitos básicos de banco de dados e análise de dados.

## Tecnologias utilizadas
- PostgreSQL
- SQL
- pgAdmin 4

## Estrutura do banco de dados
- clientes
- produtos
- vendas

## Análises realizadas
- Produtos mais vendidos
- Clientes que mais gastaram
- Faturamento mensal

## Objetivo
Projeto criado para aprendizado e para utilização em processos seletivos na área de dados.
